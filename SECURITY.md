# Security Policy 🛡️

## Supported Versions

We issue security patches for the latest version of **avKeyWallet**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

Security is the top priority of this project. If you discover a security vulnerability, memory leak, or cryptographic flaw, **please do not open a public GitHub issue**.

Instead, please report it privately:

1. **Email:** Send details to simone.martin.fi@gmail.com.
2. **GitHub Security Advisories:** You can also use the "Report a vulnerability" button under the **Security** tab of this repository.

### What to include in your report:
- A description of the flaw or vulnerability.
- Steps to reproduce or a Proof of Concept (PoC).
- Potential impact (e.g., memory exposure, vault corruption).

### Response Time:
*Note: This is an independent project maintained in spare time, so response times may vary. All valid reports will be reviewed as soon as possible.*

Thank you for helping keep **avKeyWallet** safe!
